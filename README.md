# Secure Task Manager

A secure web application developed as part of IKB21503 Secure Software Development coursework at UniKL MIIT.

## Built With
- Django (Python)
- SQLite (development)

## Security Features
- OWASP Top 10 compliance
- Role-Based Access Control (RBAC)
- CSRF protection
- Input validation
- Secure session management
- Audit logging
